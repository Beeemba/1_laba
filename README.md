# Работа с массивами на C++

Учебный проект для демонстрации работы с массивами, ссылками и range-based for.

## Возможности
- Заполнение массива случайными числами
- Вывод массива (range-based for с auto)
- Обмен элементов по индексам
- Умножение всех элементов на 2

## Требования
- Компилятор с поддержкой C++14
- Стандарт: C++14

## Сборка и запуск
Команда компиляции: g++ -std=c++14 -O2 -Wall 1_laba.cpp -o 1_laba.exe
Запуск: .\1_laba.exe

## Ключевые особенности кода
- Передача массива по ссылке: int (&arr)[10]
- Range-based for с auto для чтения
- Range-based for с int& для модификации
- Использование const для защиты данных
- Код соответствует стандарту C++14
